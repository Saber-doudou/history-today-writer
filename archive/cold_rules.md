### 1.2 Rule 31-35（四AI共性问题模式，正文源自 review_rules.md §9B）

### Rule 31. "世变"须具象化（P1强制）
当文章主旨依赖于某个历史语境时，必须提供至少2个具体事件/情境使其可感知。

涉及文化符号时，不能停留在表面描述，必须触及最深的文化含义层。

### Rule 33. 禁止自媒体过渡句（P2强制）
禁止使用"要理解XX，得先看看……"等自媒体引导式过渡句。

### Rule 34. 核心比喻须展开（P2强制）
引入强力比喻后，不能点到为止。须在后文中至少回扣一次。

### Rule 35. 结尾忌"无标准答案"式说教（P2强制）
禁止结尾使用"至今没有标准答案"等说教句式。用意象收束或引语自然收尾。

### 1.7 Rule 51（正文源自 writing_rules.md §5L）

### Rule 51: 反间计/阴谋类题材三要素
**适用场景**：涉及政治阴谋、情报战、陷害等题材
**必须包含**：
1. **伪造证据的具体方式**：文件/信件/录音等，不能只写"伪造情报"一笔带过
2. **中间人传递机制**：谁把证据送到目标手里，不能省略关键中间人
3. **目标人物的性格弱点**：为什么会被骗，强调内因（多疑、贪婪、偏见等）

**禁止**：只写"伪造情报"一笔带过，不交代具体手法
**案例**：图哈切夫斯基事件中，盖世太保伪造档案文件（伪造证据）→ 捷克斯洛伐克总统贝奈什转交（中间人）→ 斯大林多疑忌惮功高震主（性格弱点）

### 1.9 Rule 59（正文源自 writing_rules.md §5P）

### Rule 59: 受压方心理反应不可空白
**适用场景**：叙事涉及羞辱、投降、审判、处决等高压场景，且有明确的承受者
**必须执行**：至少用1个生理反应（脸色惨白/颤抖/泪流满面/指节发白等）呈现承受者的即时反应，不能只写施压方的动作而忽略承受方
**禁止**：❌ 只写施压方的胜利者姿态，承受方只有"提了修改意见"等事务性动作
**案例**：贡比涅停战协定——v1只写亨齐格"提了修改意见，全被拒绝"，未呈现他走进车厢时的震惊、签字时的颤抖。4个AI一致指出这是全文最大的情感缺口

### 1.10 Rule 60-61（正文源自 writing_rules.md §5Q）

### Rule 60: 科学假说必须保留学术开放性
**适用场景**：文章涉及多个竞争性科学假说，需要讨论哪个更受认可
**必须执行**：当否定或弱化某个假说时，必须解释"为什么不够"而非直接宣布"不成立"。使用"无法单独解释一切""尚存争议"等开放性表述
**禁止**：❌ "这个理论不成立" → ✅ "该假说无法单独解释一切"
**案例**：麦角菌假说——不能说"不成立"，而应说"痉挛型中毒与记载吻合，但爆发区并非都以黑麦为主食，无法单独解释一切"
**判例来源**：详见 CASE_STUDIES.md CASE-44（4/4 AI 一致指出否定过于武断）

### Rule 61: 群体心理现象必须解释传播机制
**适用场景**：文章涉及群体性心因性疾病、集体癔症、社会恐慌等群体心理现象
**必须包含**：
1. **触发条件**：什么压力/创伤导致心理崩溃
2. **传播机制**：社会模仿效应、情绪传染、链式反应
3. **生理表现**：解离状态的具体表现（意识与身体脱节）
**禁止**：只说"群体性心理崩溃"而不解释传播过程
**案例**：舞蹈瘟疫——必须解释"第一个人开始跳→社会模仿效应→链式反应→个体苦难裹挟成集体洪流"
**判例来源**：详见 CASE_STUDIES.md CASE-44（4/4 AI 一致指出机制论述偏浅）

### 1.11 Rule 62（正文源自 writing_rules.md §5R）

### Rule 62: 技术竞争中的优势归属必须验证

**适用场景**：科技史/技术选型题材中，当叙述A方案优于B方案时

**必须执行**：
1. A方案的优势必须有具体技术原因支撑（印刷精度/识别率/成本等可验证指标），不能笼统说"更好"
2. B方案被淘汰的理由必须明确交代（至少1个具体技术缺陷）
3. 优势描述必须确认确实属于A方案——不能将B方案的优势错误归因为A

**禁止**：
- ❌ "他坚持采用直线条纹，无论商品怎么摆都能扫到"——任意角度扫描是靶心码的特征，非直线条纹
- ❌ 只写"IBM方案更好"而不解释靶心码有什么致命缺陷

**允许**：
- ✅ "靶心码在高速印刷时边缘容易渗墨模糊、识别率低。劳雷尔改用直线条纹——虽然需要对齐方向，但印刷稳定、容错率高"

**案例**：文章称直线条纹"无论商品怎么摆都能扫到"，事实上靶心码（同心圆）才支持任意角度扫描，直线条纹需要对齐方向。直线条纹的真正优势是印刷精度和识别稳定性。

**判例来源**：详见 CASE_STUDIES.md 2026-06-26 条形码首次扫描（4/4 AI一致指出技术特征描述错误）

### 1.12 Rule 64（正文源自 writing_rules.md §5U）

### Rule 64: 天文/宇宙事件须区分"撞击"与"空中爆炸"
**适用场景**：文章涉及天体（小行星/陨石/彗星）与地球大气层的相互作用事件
**必须执行**：
1. 当天体**未撞击地面前已解体气化**时，使用"空中爆炸""空爆""凌空爆炸"等术语，禁止使用"天体撞击""撞击事件"等措辞
2. 涉及大数量级数据（倒树数量、覆盖面积、能量当量等）时，必须验证数据的实际来源——多个AI同时指出的事实偏差应自动升级为P0
3. 物理现象在局部和整体表现不同时（如中心火焰被吹灭但外围持续燃烧），必须同时交代局部和整体表现，禁止只写单方面
**禁止行为**：❌ "地球上有记录以来最强大的天体撞击事件" → ✅ "地球上有记录以来最强大的天体空中爆炸事件"
**允许**：✅ "不是天体撞击了地球，是大气层替大地承受了这一击"
**判例来源**：详见 CASE_STUDIES.md CASE-24

### 1.13 Rule 65（正文源自 writing_rules.md §5V）

### Rule 65: 环境/资源危机事件必须包含关键政策转折节点
**适用场景**：文章涉及自然资源枯竭、环境灾难、渔业/林业/水资源管理等题材
**必须执行**：
1. 至少交代一个影响事件走向的关键政策/法规节点（如专属经济区、补贴政策、配额设定机制、环保法规等）
2. 说明该政策是缓解还是加剧了危机，形成完整的"技术→政策→生态"因果链
3. 涉及政府管理失当的题材，必须交代政治决策（如选票考量、产业游说）如何放大了技术问题
**禁止行为**：❌ 只写"过度捕捞/过度开采"而不解释制度层面如何纵容或放大了贪婪
**允许**：✅ "1977年加拿大划定200海里专属经济区，赶走外国船队。这本是纠错的机会，但政府转头用补贴鼓励本国渔民扩张，力度反而更大"
**案例**：1992年鳕鱼崩溃中，1977年200海里专属经济区是全文最关键的因果转折——驱逐外国船队→补贴本国扩张→捕捞反而加剧，完整呈现了"技术贪婪→政策失当→生态崩溃"的三层因果链
**判例来源**：详见 CASE_STUDIES.md CASE-25

### 5V.1 自检清单
- □ 文章是否涉及自然资源/环境管理题材？

### 1.14 Rule 66（正文源自 writing_rules.md §5W）

### Rule 66: 物种灭绝/濒危事件必须包含生物学约束条件和关键转折事件
**适用场景**：文章涉及物种灭绝、濒危、生物多样性丧失等题材
**必须执行**：
1. **交代繁殖率/恢复力**：至少说明该物种的繁殖特征（如繁殖率、繁殖周期、幼崽存活率等），让读者理解"为什么捕杀会导致无法恢复"
2. **交代关键转折事件**：如果物种灭绝存在一个决定性的前置事件（如自然灾害摧毁核心栖息地、最后一次大型捕杀事件等），必须交代该事件，否则因果链在"种群锐减→彻底灭绝"之间跳跃
3. 形成完整的"资源消耗→生物学约束→关键转折→最终灭绝"因果链
**禁止行为**：
- ❌ 只写"过度捕杀导致灭绝"而不解释为什么该物种难以从捕杀中恢复
- ❌ 当存在关键转折事件（如火山摧毁栖息地）时却不提及，让读者觉得"最后几只被杀死=灭绝"太突兀
**允许**：
- ✅ "每年只产一枚蛋，夫妻轮流孵化——这种极低的繁殖率，注定了它们经不起持续的猎杀"
- ✅ "1830年一场海底火山爆发摧毁了大海雀最后的核心繁殖地，仅四十对幸存"
**案例**：大海雀灭绝中缺失的两个关键约束：①繁殖力极弱(每年1枚蛋) 3/4 AI一致补充；②1830年火山爆发摧毁繁殖地 3/4 AI一致补充
**判例来源**：详见 CASE_STUDIES.md CASE-40

### 1.15 Rule 67（正文源自 writing_rules.md §5X）

### Rule 67: 动物/战争史题材必须有贯穿全文的人宠情感主线
**适用场景**：涉及动物（尤其是战犬/战马等服役动物）与人类关系的历史叙事
**必须执行**：
1. 动物与主人的情感关系必须贯穿全文，不得在核心叙事段中让主人"消失"
2. 主人应在动物的每个关键事迹中持续出现（收养→并肩作战→危机救助→荣誉共享），形成完整的情感弧线
**禁止行为**：
- ❌ 开篇写收养后将主人丢弃，到结尾才重新出现
- ❌ 只写动物本身的功绩，不交代人与动物之间的具体互动细节
**允许**：✅ "康罗伊抱着它冲进野战医院，以为它挺不过来了。从死亡线上回来的斯达比，嗅觉变得异常敏锐"
**判例来源**：详见 CASE_STUDIES.md 2026-07-06 斯达比中士

### 5X.1 自检清单
- □ 文章是否涉及服役动物与人类的关系？
- □ 动物主人/训导员是否在每个关键事迹中持续出现？
- □ 人与动物的互动是否有具体细节（而非仅"陪伴"概括）？
- □ 情感弧线是否完整（偶遇→信任→危机→升华）？

### 1.16 Rule 69（正文源自 writing_rules.md §5Y）

### Rule 69: 技术/打法时代背景须核实（P1强制）
**适用场景**：涉及某项技术/打法"近乎失传/被复兴/回潮"等时代判断表述
**必须执行**：核实该时代该技术是否真式微，禁止套用"复兴"叙事模板。若该技术当时正值鼎盛，应如实写"最具杀伤力的武器"而非"失传后复兴"
**禁止行为**：❌ "把'发球上网'这门近乎失传的打法重新变成一种艺术"（1980年代发球上网正值鼎盛，非失传）→ ✅ "他最锋利的武器，正是那个年代温布尔登草地上最具杀伤力的发球上网"
**判例来源**：详见 CASE_STUDIES.md CASE-27（2026-07-07 贝克尔篇——v1"发球上网近乎失传"被千问/豆包点出时代误判）

### 1.17 Rule 92/93/100/101（2026-09-11 Curator 棘轮 B 档降 cold，正文自 writing_core.md / topics/war_institution.md 逐字迁移）

### Rule 92: 盟誓/结盟标志时刻的语言文化细节须呈现（P2强制）

**触发条件**：涉及结盟/盟誓/谈判/条约签订等标志性时刻，且存在语言/文化/仪式层面的标志性细节时。

**必须执行**：
1. 挖掘并呈现标志性细节（互誓使用对方语言、留下最早书面文献、仪式动作等）
2. 用 1-2 句把细节与主题勾连，让细节成为文化断裂的证据而非孤立花边

**禁止行为**：
- ❌ 对标志性时刻仅一笔带过（"立誓结盟"四个字结束），浪费兼具故事性与学术价值的细节

**允许**：
- ✅ "为了让对方军队听懂，路易用罗曼语（古法语的雏形）宣誓，查理则用条顿语（古高地德语的雏形），这份互誓文献成了欧洲现存最早的罗曼语与日耳曼语书面记录"

**判例来源**：2026-08-10 凡尔登条约 L2 学习（ds/ima/千问/豆包 4/4 共识：斯特拉斯堡双语互誓是帝国文化断裂的标志性证据，v1 仅一笔带过；豆包"路易用德语/查理用法语"为语序颠倒单源，不采信，维持 ds/ima"路易用罗曼语/查理用条顿语"口径）

### Rule 93: 古代题材副标题加注"对应中国朝代/年号"（P2强制）

**触发条件**：涉及古代/中世纪历史事件（尤其外国史、朝代更迭/帝国兴亡类），时间行出现明确公元纪年，且对应中国某个朝代/年号时。

**必须执行**：
1. 副标题时间行加注对应中国朝代/年号，格式："843年8月（唐武宗会昌三年）· 凡尔登（今法国东北部）"
2. 朝代标注精确到年号（会昌三年），不只写宽泛朝代（"唐代"）
3. 公历年份→中国年号换算须核验（万年历/年号表，避免换算错误）

**禁止行为**：
- ❌ 中国本土古代事件重复标注（本身即中国语境，无需加注）
- ❌ 年份/年号换算错误（如将 843 年误标为其他年号）
- ❌ 标注冗长挤占副标题（控制在括号内一句）

**允许**：
- ✅ "843年8月（唐武宗会昌三年）· 凡尔登（今法国东北部）"
- ✅ "公元前44年（西汉元帝初元五年）· 罗马"

**判例来源**：2026-08-10 凡尔登条约 Master 指示（时间对应前置提升读者时间线认知，尤适朝代更迭/帝国兴亡类；首例应用获 Master 认可"感觉还不错"）

### Rule 100: 封锁/筑墙/戒严类行动须区分"当晚部署"与"后续数日部署"（P1强制）

**触发条件**：描述封锁/筑墙/戒严/军事行动首日场景时，把随后数日才部署的重型装备（坦克、重型装甲等）写入当晚，造成"装备同步部署"的史实偏差。

**必须执行**：
1. 首日场景只写当晚实际部署物（铁丝网、水泥路障、停运、封锁路口等），按当日史实写
2. 重型装备确需出现，须标注时序（"随后几天，坦克开到边界"），不得与当晚场景并置

**禁止行为**：
- ❌ "探照灯和坦克随后跟上"——坦克等重型装备并非当晚同步部署（1961.8.13 凌晨行动以铁丝网/水泥路障为主）

**允许**：
- ✅ "探照灯刺破夜空；地铁停运，路口全部封锁。"

**判例来源**：2026-08-13 柏林墙 L2 学习（豆包明确指出"坦克随后跟上"不符合史实——当日凌晨以铁丝网、水泥路障为主，重型装备非同步部署）→ CASE-50

### Rule 101: 国际对抗/封锁类事件须交代"对方/国际社会反应"（P2强制）

**触发条件**：叙事核心是国际对峙/封锁/制裁/危机（柏林封锁、核危机、贸易战等），只写行动方视角会让冷战博弈维度缺失，事件像"单方面发生"，读者不知另一方为何容忍或干预。

**必须执行**：
1. 至少1句交代对方或国际社会的反应（默认/抗议/干预/增兵/制裁）
2. 反应放在行动落地之后、后果展开之前，作为因果链一环

**禁止行为**：
- ❌ 全文只有行动方视角，读者不知另一方为何容忍/干预

**允许**：
- ✅ "西方盟军默认了它：肯尼迪不愿为柏林冒险，只增兵守住西柏林。"

**判例来源**：2026-08-13 柏林墙 L2 学习（ds/ima/豆包 3/4 指出 v1 缺美苏反应、西方为何不干预；ds 补充肯尼迪增兵/派副总统约翰逊安抚）→ CASE-50
