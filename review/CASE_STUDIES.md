## 2026-06-01 | 尼泊尔王室惨案

**四家一致指出的问题（8项）**：

1. **"摔碎酒杯"无史料依据（P0）** — 千问明确指出当晚是"醉酒失态被父亲训斥后由弟弟和堂弟搀扶回房"。Rule 13的"核心事实100%准确"不仅适用于人名/数字，也适用于关键动作细节。
2. **动机描写太简单（P1）** — 需展现酗酒、吸毒、精神崩溃的渐进过程。"伊顿精英→醉酒吸毒→持枪屠杀"的反差弧线本身就是最好的叙事素材。
3. **政治动因简化过度（P1）** — 需交代拉纳家族政治死敌+反印情绪+最后通牒具体内容（两个选项）。
4. **阴谋论"只抛问题不给线索"（P1）** — 需补充具体异常（左撇子伤口、贾南德拉在博卡拉、其子提前离席、一家人毫发无损）。
5. **死亡人数表述模糊（P1）** — 应区分"九名王室成员遇害"和"迪彭德拉本人"。
6. **道德评价过重（P2）** — "一颗母亲不肯松手的执念"像判词。DS点评："冷叙述的魅力在于让事实自己说话，不需要作者替读者下结论。"
7. **缺少"十世而斩"诅咒（P2）** — 民间传说增加宿命感。
8. **"伊顿精英"与"冷血杀手"反差铺垫不足（P1）**。

**各版独特贡献**：

| 来源 | 贡献 |
|------|------|
| DS | 优化标题"当他成为国王时，已经无法醒来"；法理细节（摄政王代行职权）；冷叙述风格示范 |
| IMA | "十世而斩"诅咒开篇；最后通牒具体内容（两个选项）；贾南德拉妻儿在场却轻伤 |
| 千问 | 保镖规矩（不得进入家宴）；翻窗求救细节；左撇子伤口异常；德芙雅尼结局（嫁印度商人）；摔碎酒杯史料纠正 |
| 豆包 | 弟弟跪地求情（Show Don't Tell）；王后逃入花园被射杀 |

**v1→v2改动清单**：

- 标题："一桩婚事毁掉一个王朝" → "当他成为国王时，已经无法醒来"
- 开篇：感官场景 → "十世而斩"诅咒传说
- "摔碎酒杯离席" → "醉酒失态，被父亲训斥，由弟弟和堂弟搀扶回房"
- 政治动因：王后一人反对 → 拉纳家族政治死敌+反印红线+最后通牒两个选项
- 心理铺垫：几乎没有 → 酗酒、吸毒、精神崩溃
- 阴谋论：空洞问题 → 左撇子伤口+博卡拉度假+其子提前离席
- 新增：保镖规矩、翻窗求救、德芙雅尼结局
- 删除：道德评价"母亲不肯松手的执念"

**提炼的通用规则**：
- → Rule 26：情节细节需史料来源
- → Rule 27：阴谋论需具体异常
- → Forbidden Pattern #12：情节细节凭空添加

## 2026-05-29 | 爱尔兰皇后号沉没

**四家一致指出的问题（3项）**：

1. **倒车细节缺失** — Storstad倒车退出→裂口暴露→进水翻倍是因果链核心环节。
2. **手动水密门未点出** — 皇后号水密门必须手动关闭（vs泰坦尼克可自动），这是14分钟沉没的技术死穴。
3. **救世军段落单薄** — 167人仅一笔带过。展开手法：身份（年轻乐手）+目的（赶往伦敦大会）+记忆点（空椅子摆着乐器）。

**各版独特贡献**：DS=倒车细节+Storstad破冰船艏；千问=女性数据+空椅子乐器+深度对比；IMA/千问/豆包=手动水密门表述。

**提炼的通用规则**：灾难因果链必须完整；技术设计缺陷是"为什么"的答案；数据口径必须统一（P0级）；不可考证数字不如可感知描写；特殊群体需要展开而非罗列。
